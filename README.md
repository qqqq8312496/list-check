# 对得上 · 名单核对与补全

无需 API、无需服务器的静态网页工具。所有数据在当前浏览器内读取和处理，不会上传文件，也不会保存到浏览器持久存储。

## 打开方式

解压整个文件夹，双击 `index.html`，或双击 `打开工具.bat`。请保留 `vendor` 文件夹、JS 和 CSS 文件与页面的相对位置。可直接离线使用，不需要 Python、Node.js、Excel 或任何安装步骤。推荐使用新版 Edge / Chrome。

也可以将 `index.html`、`app.js`、`core.js`、`styles.css`、`vendor/` 和 `.nojekyll` 一起上传到 GitHub Pages 等静态托管。手机通过网页链接使用；本版本的手机布局经过桌面浏览器模拟检查，尚未在实体 iPhone / Android 上验证。

## 名单核对

1. 导入两张 Excel / CSV 表，或粘贴表格内容。
2. 确认工作表、表头和数据范围，分别选择需要核对的一列。
3. 可选配对的辅助列，例如工号。两表必须同时选择辅助列。
4. 默认只显示差异；“重复 / 重名”单独显示任一表出现多次的对应值。“次数一致”不代表人员身份已确认。
5. 展开记录查看原始行号和完整内容；导出包含差异、重复、完整结果及处理规则的 XLSX。

## 补充资料

1. 表 A 是主表，表 B 是资料来源。
2. 选择对应列，勾选资料表中要补充的字段。
3. 主表保留非全空数据行的顺序、字段和值；新增字段追加到右侧。
4. 两侧对应值均唯一才自动补充。重名请使用辅助列，或展开记录手动选择来源；不自动取第一条、不扩增主表行数。
5. 未匹配、来源空值、对应字段缺失单独提示。导出含补全主表、待核查项、所有来源行号与手动确认记录。

## 表头和格式

- 支持 XLSX、旧版二进制 XLS（BIFF）、常见 HTML 表格形式的 XLS、CSV，以及制表符粘贴。
- CSV 支持 UTF-8、带 BOM 的 UTF-16，以及 UTF-8 无法解码时尝试 GB18030。
- 自动表头识别只作建议。可在原表任意位置指定多行表头、数据起止行；也支持无表头。
- Excel 合并范围用于解释表头，列名包含父级表头，并始终显示列字母。
- 所选匹配列或待补字段的数据区如果存在合并单元格，会停止并提示先明确拆分；不会自行展开并计数。
- 全空行跳过；姓名或辅助字段缺失不参与自动匹配。补资料时主表的非空记录保留。
- 比较默认忽略前后空白，保留字段内空格、大小写、前导零、同音字与简繁体差异。可在高级规则内调整空格和大小写。
- 使用单元格现有显示值，公式不重新计算。导出为字符串或明确的统计数字，不把用户文本转换为公式。
- 不重建原文件的合并排版、宏、图片或公式。已经在源文件中丢失精度的长数字无法恢复；长数字和无缓存公式会提示核查。
- 加密文件须先解除密码。当前文件上限 40 MB，工作表范围上限 100,000 行 / 500 列 / 200 万单元格。
- 隐藏行和 Excel 筛选隐藏的行，只要位于所选数据范围内，均参与处理；当前不读取筛选结果作为排除依据。
- 手动确认仅表示用户指定对应，允许多个主表行选择同一个候选来源，导出可审计来源行号。

## 本地验证

使用 Node.js 执行：`node --test tests/core.test.js`。

浏览器测试使用 Playwright 和 Edge：运行本地静态服务器后，执行 `node tests/browser.test.js`。可通过 `PLAYWRIGHT_MODULE` 环境变量指定 Playwright 模块路径。测试覆盖真实 XLS / XLSX 导入、复杂表头、乱序匹配、重名、人工确认、导出回读、离线粘贴及手机宽度布局。测试所用数据全部为模拟数据。

## 第三方组件

SheetJS Community Edition 0.20.3，Apache-2.0 许可证。文件和许可证位于 `vendor/`，运行时无 CDN 依赖。
